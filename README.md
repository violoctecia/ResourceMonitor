# Resource Monitor

*[English version](README.en.md)*

Лёгкая менюбарная утилита для macOS, которая показывает, кто на самом деле жрёт память и CPU — и помогает поймать забытые в фоне процессы: dev-серверы на портах, Docker-контейнеры, зависшие приложения.

Идея простая: при активной разработке на Mac постоянно копятся фоновые процессы — dev-серверы, Docker-контейнеры, — которые продолжают работать после переключения между проектами и незаметно едят ресурсы, пока не начинает тормозить вся система.

Одна иконка в menu bar, без сторонних зависимостей (SwiftBar и т.п.) — нативное Swift/AppKit-приложение.

## Что показывает

- **CPU / RAM** — общая загрузка системы, прогресс-барами
- **Приложения** — топ по потреблению памяти/CPU, сгруппированный по реальному приложению (все процессы Chrome — одной строкой, а не десятком helper-процессов)
- **Прослушиваемые порты** — какой процесс на каком порту висит, сколько жрёт, сколько работает, и (если это dev-сервер) из какой папки проекта запущен
- **Docker контейнеры** — то же самое для запущенных контейнеров

Каждая строка подсвечивается по потреблению ресурсов:
- 🟢 зелёный — всё в порядке
- 🟡 жёлтый — от 150MB RAM или 15% CPU — стоит присмотреться
- 🔴 красный — от 500MB RAM или 50% CPU — стоит проверить, нужен ли ещё

## Что можно сделать прямо из меню

- **Kill** процесса, слушающего порт
- **Stop** Docker-контейнера
- **Quit** приложения (штатный AppleScript quit, а не `kill -9`, — приложение может спросить сохранить несохранённое)
- Переключить язык интерфейса (Русский / English)
- Включить автозапуск при входе в систему

## Требования

- macOS 13.0+ (нужен для автозапуска через `SMAppService`)
- Docker — опционально, если не установлен, соответствующая секция просто покажет "не найден"

## Установка

**Вариант 1 — готовый билд (проще всего):**

1. Скачай `ResourceMonitor.zip` со страницы [Releases](../../releases/latest)
2. Разархивируй и перетащи `ResourceMonitor.app` в `/Applications`
3. Запусти **правым кликом → Открыть** (а не двойным кликом) — приложение не подписано Apple Developer сертификатом, поэтому при первом запуске macOS покажет предупреждение "не удалось проверить разработчика". Правый клик → Открыть → подтвердить в диалоге — дальше запускается как обычно

**Вариант 2 — собрать из исходников** (нужен только Xcode Command Line Tools, полноценный Xcode не требуется):

```bash
git clone https://github.com/violoctecia/ResourceMonitor.git
cd ResourceMonitor
swiftc -O -o ResourceMonitor.app/Contents/MacOS/ResourceMonitor main.swift -framework Cocoa -framework ServiceManagement
cp Info.plist ResourceMonitor.app/Contents/Info.plist
codesign --force --deep --sign - ResourceMonitor.app
cp -R ResourceMonitor.app /Applications/
open /Applications/ResourceMonitor.app
```
